# Contribution à Inspiration e-shop

Voici quelques lignes directrices pour vous aider à démarrer. Merci de votre intérêt pour ce projet ! 

## Comment contribuer

1. **Fork le dépôt** : Créer votre copie du projet.
2. **Créer une nouvelle branche** : Utiliser un nom descriptif pour votre branche (`amelioration-fonctionnalite`).
3. **Faire vos modifications** : Apporter les améliorations ou corrections nécessaires.
4. **Commiter vos changements** : Rédiger des messages de commit clairs et descriptifs.
5. **Ouvrir une pull request** : Soumettre vos modifications pour examen.

## Bonnes pratiques

- Respecter le style de code existant.
- Documenter les modifications.
- Tester les modifications avant de les soumettre.

Merci pour vos contributions !
